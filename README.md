# React Plant Shop Application

## Overview

This project is a guided React application under development, simulating a plant e-commerce website called Maison Jungle.
It focuses on component-based development, JSX, state management, and hooks.

## Features

- React components
- JSX syntax
- State management with hooks
- Interactive user interface

## Tech Stack

- React
- JavaScript
- HTML / CSS

## Installation

### Clone the Repository

- `git clone https://github.com/fabroyer/react-shop-app.git`
- `cd react-shop-app`

### Install Dependencies

```bash
yarn install
```

## Usage

### Run the Development Server

```bash
yarn start
```

Open in browser: http://localhost:3000/

### Run Tests

```bash
yarn test
```

### Build for Production

```bash
yarn build
```
